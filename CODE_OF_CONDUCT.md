# Code of conduct

## Our standards

RepoCare contributors commit to a respectful, harassment-free community. Be constructive, assume good intent, respect different levels of experience, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discriminatory language, threats, publishing private information, or sustained disruption.

## Enforcement

Report conduct concerns privately to the project maintainers through the contact method listed on the maintainer's GitHub profile. Maintainers may edit or remove content and temporarily or permanently restrict participation when needed to protect the community.

This policy is adapted from the Contributor Covenant's core expectations.
